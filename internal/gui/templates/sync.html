Connect to Google

To sync with Google Calendar and Sheets, you need a credentials file from Google. This is a one-time setup that takes about 5 minutes.

Step 1: Go to Google Cloud Console. Sign in with the Google account you want greenies to use.

Step 2: Create a new project. Click the project dropdown at the top of the page, then "New Project". Name it anything — "greenies" works fine.

Step 3: Enable three APIs. Go to APIs & Services → Library and search for each of these, then click "Enable":

  • Google Calendar API
  • Google Tasks API
  • Google Sheets API

Step 4: Set up the consent screen. Go to APIs & Services → OAuth consent screen. Choose "External", fill in the app name ("greenies") and your email, then save. Under "Test users", add yourself.

Step 5: Create credentials. Go to APIs & Services → Credentials, click + Create Credentials → OAuth client ID. Application type: "Desktop app". Name: "greenies". Click "Create", then "Download JSON".

Step 6: Move the downloaded file to:

~/.greenies/credentials.json

The download will have a long name — rename it to credentials.json.

Step 7: Come back here and reload this page. You'll see a "Sign in with Google" button.

After this one-time setup, syncing is just one click.

This creates a spreadsheet called "greenies" in your Google Drive with four tabs: Crops, Cycle, Farm, and Trials. Your existing local data will be uploaded automatically. You'll be able to view and edit your crop library and farm layout from any device.
